# Calendar

Сервис записи на звонок по мотивам Cal.com: гость без регистрации записывается на звонок, выбирая
свободный слот, а владелец заводит типы событий и видит список предстоящих записей. Приложение
намеренно ограничено: один заранее заданный владелец, без авторизации и интеграций с внешними
календарями.

## Language

**Тип события** (Event Type):
Вид встречи, который заводит владелец: название, описание и длительность в минутах (5–720).
Идентификатор типа присваивает система. Тип бывает действующим или архивным.
_Avoid_: Тип встречи, meeting type

**Архивный тип** (Archived type):
Тип события, скрытый от выбора гостя, но чьи записи сохраняются.
_Avoid_: Удалённый тип, скрытый тип

**Слот** (Slot):
Полуинтервал свободного времени `[start, start + длительность)` внутри рабочих часов, который
гость может занять.
_Avoid_: Интервал, тайм-слот, окно времени

**Запись** (Booking):
Факт занятия гостем слота по определённому типу события; несёт имя гостя, email, заметку и время
в UTC.
_Avoid_: Бронь, бронирование, резерв, appointment

**Гость** (Guest):
Человек без регистрации, который записывается на свободный слот.
_Avoid_: Клиент, пользователь, посетитель

**Владелец** (Owner):
Единственный заранее заданный владелец календаря; заводит, правит и архивирует типы событий,
просматривает предстоящие записи и удаляет их.
Его экран в интерфейсе подписан «Админка».
_Avoid_: Администратор, host

**Рабочие часы** (Business hours):
Ежедневный интервал 09:00–21:00 в поясе владельца (`Asia/Yekaterinburg`), внутри которого
существуют слоты.
_Avoid_: График, доступность

**Окно записи** (Booking window):
Четырнадцать календарных дней от «сегодня» в поясе владельца, в пределах которых гость выбирает
слот.
_Avoid_: Период бронирования
