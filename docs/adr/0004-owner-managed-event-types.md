# Типы событий управляются владельцем

Владелец заводит, правит и удаляет типы событий; идентификатор типа присваивает система. Это
отменяет ADR-0003 «типы фиксированы»: бриф требует управления типами. Тип, у которого уже есть
записи, не удаляется, а архивируется, чтобы не терять историю; изменение длительности не трогает
существующие записи.
