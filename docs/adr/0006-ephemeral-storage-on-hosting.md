# Эфемерное хранение на хостинге

На публичном хостинге (Render Web Service, Environment Docker) SQLite-файл лежит внутри
контейнера. Данные переживают перезапуск процесса, но **не** пересоздание контейнера: при
редеплое, смене образа или переносе инстанса без внешнего тома файл исчезает вместе с
контейнером, и после редеплоя без тома данные сбрасываются.

Этим решение ограничивает ADR-0001 «SQLite для хранения»: обещание «переживать рестарт»
остаётся в силе для перезапуска процесса, но не распространяется на замену контейнера. Внешний
том сознательно не заводим: проект учебный, а том усложнял бы деплой и проверку; ограничение
фиксируется явно, чтобы README и проверяющий знали про сброс. Если сохранение данных между
деплоями понадобится, решение переоткрывается — внешний том или управляемая БД.
