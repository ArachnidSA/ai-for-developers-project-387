# Шаг стартов слотов равен длительности типа

Слоты одного типа идут встык: старт следующего — ровно через длительность типа, а не по общей
сетке. При произвольных длительностях общий шаг оставлял бы «мёртвые» промежутки, а непересечение
разных типов всё равно проверяется по фактическим интервалам `[start, end)`.
