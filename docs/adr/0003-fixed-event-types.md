# Типы событий фиксированы

В приложении ровно два типа события («Встреча 15 минут» и «Встреча 30 минут»), заданные как
константы; владелец их не создаёт, не редактирует и не удаляет. Это сознательное отступление от
исходной спеки («владелец заводит типы встреч») ради минимизации скоупа: управление типами можно
добавить позже отдельной таблицей и CRUD, не ломая остальное.
