# SQLite для хранения

Типы событий и записи хранятся в SQLite через SQLAlchemy. Выбрали постоянную БД, а не in-memory
или JSON-файл, потому что приложение должно переживать рестарт, а атомарную гарантию «нельзя
занять слот дважды» проще обеспечить транзакцией в БД, чем блокировкой в памяти или перезаписью
файла.
