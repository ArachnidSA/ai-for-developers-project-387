# Triage Labels

Скилы говорят о пяти канонических ролях triage. Этот файл маппит роли на реальные строки меток,
используемые в трекере этого репозитория.

| Роль в mattpocock/skills | Метка в нашем трекере | Смысл |
| ------------------------ | --------------------- | ----- |
| `needs-triage`           | `needs-triage`        | Мейнтейнеру нужно оценить issue |
| `needs-info`             | `needs-info`          | Ждём от автора дополнительной информации |
| `ready-for-agent`        | `ready-for-agent`     | Полностью описано, готово для AFK-агента |
| `ready-for-human`        | `ready-for-human`     | Нужна реализация человеком |
| `wontfix`                | `wontfix`             | Обрабатывать не будем |

Когда скил упоминает роль (например, «применить метку AFK-ready»), используй соответствующую
строку из этой таблицы.

Редактируй колонку «Метка в нашем трекере», чтобы она совпадала с вашим словарём меток.

Метки `wayfinder:map` и `wayfinder:<type>`, которые нужны `/wayfinder`, в этот файл не входят и
в трекере пока не созданы — заведи их, когда впервые запустишь `/wayfinder`.
